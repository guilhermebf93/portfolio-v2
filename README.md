# 🚀 Portfolio V2

Meu novo portfólio pessoal desenvolvido com foco em performance, experiência do usuário e uma interface moderna.

O projeto foi construído do zero utilizando React, TypeScript e Tailwind CSS, trazendo uma arquitetura mais organizada, componentes reutilizáveis e animações suaves para criar uma navegação fluida e agradável.

## ⚙️ Instalação e Uso

### Clone o repositório

```bash
git clone https://github.com/guilhermebf93/portfolio-v2.git
```

### Entre na pasta do projeto

```bash
cd portfolio-v2
```

### Instale as dependências

```bash
npm install
```

### Rode o projeto

```bash
npm run dev
```

O projeto ficará disponível em:

```txt
http://localhost:5173
```
